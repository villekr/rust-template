# AGENTS.md

# Conversation style

- You must focus on efficient communication. You must use minimal words.
- Results matter, not explanations.
- I won't always thank you for good work. I appreciate you regardless.

# Content creation

- Only create files when explicitly asked.
- No unsolicited documentation, summaries, or "helpful" extras.
- If something is needed, it will be requested.

# Project

- See README.md for the tech stack, project structure, and dev workflows.

# Contribution workflow

- `main` is protected: never commit or push directly to it.
- All changes go through a pull request from a feature branch.
- Use Conventional Commits for commit messages and PR titles
  (e.g. `feat: ...`, `fix: ...`, `chore(deps): ...`, `docs: ...`).
  A pre-commit `commit-msg` hook and a CI check enforce this.
